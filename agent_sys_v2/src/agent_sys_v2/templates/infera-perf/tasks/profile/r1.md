## 任务描述

- 对象：@baseline/r1 的 v0 曲线和它的 run 目录、噪声、系统采样。
- 模式：standard（默认，不用 ultracode）。onboarding（引擎第一次接入，没有 playbook）和 deep 要先经我批准，并在任务配置里打开 `agent: {ultracode: true}`；没有 playbook 时先停下来问我。

## 要做的事

- 按 skill infera-profile 的 P0–P6：先读引擎的 playbook（`playbooks/<引擎>.md`）；P1 时间账、P2 资源利用率判出瓶颈层；只对瓶颈层做 kernel 级（P3）或 CPU 路径（P4）分析；P5 写候选；P6 由核实子 agent 独立重算关键数字。
- 计分窗口只开零侵入的采集；kernel trace 放在不计分的诊断 run 或固定 batch 的台架上（机器在任务配置里）。
- 不起草实验任务：候选交给 plan。

## 交付

- `report.md`：以"## 结论"开头：瓶颈、时延税、容量风险、前 3 个候选及预期区间、是否建议 deep 及理由。
- `candidates.yaml`（infera.candidates/v1）、`profile.json`、`verify.md`。
