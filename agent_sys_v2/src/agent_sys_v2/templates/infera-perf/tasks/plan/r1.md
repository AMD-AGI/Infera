## 要做的事

1. 读台账和已完成任务的报告，去掉已经否掉的方向；配置和拓扑类先做，代码类后做；按"预期收益 / 节点·小时"排序。

3. 起草实验子任务（草稿，不要开始执行），放在 `tasks/experiment/` 下，名字带轮次前缀（例如 `r1-spf.md`）：一个子任务对应一个大杠杆，或一组同层、同验证方法的小杠杆（< 1% 的改动单独测不出来）；frontmatter 写 `parent`（本任务）、`summary`、`machines`、`expect`（预期 ΔY 区间、快速验证级别 L0–L5、证伪条件，格式见 skill infera-round）。

5. 起草完就把本任务标为完成，不要等子任务：等待由收尾任务的 children 依赖负责。
