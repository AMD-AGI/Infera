## 3. 手动操作

以下命令都在登录节点执行（home 在两台节点上共享）。先设：

```bash
W=/mnt/m2m_nobackup/liyingli_3p1d/mix-v0522
Q=/home/liyingli/bench_agentx/baseline/Infera/llying/prefill-car-20261023
R=/home/liyingli/bench_agentx/baseline/Infera/llying/2p1d-v0522-20261020
KIT=/home/liyingli/bench_agentx/baseline/2p1d-kit/ex-exp
L=$W/2p1d/async
```

**看进度**（驱动输出、当前点日志、容器、显存）：

```bash
ssh crsuse2-m2m-138 "tail -5 \$(ls -t $L/driver-*.out | head -1); ps -eo pid,args | grep -E '[p]erf_plan|[p]d_perf_chain' | cut -c1-100; docker ps --format '{{.Names}}' | grep glm52_2p1d; rocm-smi --showmeminfo vram --csv"
```

每点的 AgentX 日志是 `$L/<label>/c<C>.log`（`grep -a 'Warmup complete'` 看计分开始，计分 3,600 s；`agentx exited` 和 `down` 出现在 `driver-*.out`）。
引擎崩溃或 15 分钟无完成时 `pd_perf_chain.sh` 的 guard 会停客户端并撤栈。

**驱动死了或想手动跑剩下的点**：先确认没有残留（`docker ps -a | grep glm52_2p1d` 在两台节点上都为空、`ps` 里没有 `pd_perf_chain`），把 `$L/plan.txt` 里已完成的行删掉
（或另写一个 plan），然后：

```bash
ssh -f -n crsuse2-m2m-138 "cd $KIT && setsid nohup bash $Q/scripts/perf_plan.sh $KIT $L $L/plan.txt > $L/plan-manual-\$(date -u +%m%dT%H%M).out 2>&1 < /dev/null &"
```

plan 一行一个点："标签 站点文件 并发 [变量=值 ...]"，值里的空格用 `|`（例 `PREFILL_EXTRA_ARGS=--pp-async-batch-depth|1`）。站点文件里写了的变量会覆盖行里的值，
所以开关变量不要写进站点文件。只跑一个点也可以直接：

```bash
ssh -f -n crsuse2-m2m-138 "cd $KIT && PREFILL_EXTRA_ARGS='--pp-async-batch-depth 1' setsid nohup bash $R/scripts/pd_perf_chain.sh $KIT $R/config/site-exp-2p.env $L/async-2p-c176 176 > $L/manual-c176.out 2>&1 < /dev/null &"
```

`pd_perf_chain.sh` 会等两台节点所有 GPU 显存 < 1% 再起栈（开 HiCache 撤栈后 138 要 10–50 分钟），整栈重启、`SIM_ACCEPT_LEN=3.61`、3,600 s、撤栈前存 `/metrics`。
同一时间只跑一个点；同节点有别的任务卡在显存回收时，等待要显式盯前一个进程（见主报告"操作上的两点"）。

**收集一个点的结果**（在 138 上执行，`<RUN>` 是 `$W/2p1d/work/runs/` 下对应的目录，`ls -td $W/2p1d/work/runs/c176-* | head -1`）：

```bash
RUN=<run 目录>; D=$R/results/<名字，如 async-2p-c176>; mkdir -p $D
cp $RUN/engine-config.env $RUN/workers.json $RUN/agentx/{runtime.env,benchmark_command.txt,agentx_conc*.json,metrics_plots.png} $D/
cp $RUN/agentx/aiperf_artifacts/profile_export_aiperf.{csv,json} $D/; cp $RUN/metrics/*.prom $D/
cd $R/results && python3 ../scripts/summarize_points.py <名字>                       # 表格行
python3 $R/scripts/analyze_pd_logs.py $RUN <计分开始> <计分结束>                       # 时间写成 2026-10-24T02:58:00；prefill 新算 / 排队、decode 在跑 / 步长
python3 $R/scripts/pp_stage_times.py $RUN/logs/glm52_2p1d-prefill0.log <开始> <结束>   # PP 各级时间差与节拍
```
