### 根因排查计划（03:55 起，用户同意需要 root cause）

开发容器）在 6.19 节点上运行正常，暗示更新的 ROCm 用户态可能就能解决。

**04:05 找到最可能的根因**：kit README 第 5 条已经记录过这个崩溃——"在 dma-buf 注册会失败的网卡 provider 上，prefill 各 rank 起栈时崩在
