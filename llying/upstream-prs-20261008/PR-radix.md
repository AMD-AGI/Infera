Stock SGLang v0.5.18, used by the default mi35x image, rejects Decode radix cache whenever speculative decoding is active. Forwarding the flag from Infera alone cannot enable this combination. This PR supplies both halves of the opt-in.

- Infera forwards `--disaggregation-decode-enable-radix-cache` under speculation only when `SGLANG_EXPERIMENTAL_DECODE_RADIX_SPEC=1`, while retaining its existing KV-event, role, transport and model/topology checks.
- `Dockerfile.sglang` applies an engine admission patch when building the mi35x image. It bypasses only the speculative-decoding rejection, only for the same explicit runtime opt-in and EAGLE/NEXTN with top-k 1. Runtime behavior remains unchanged by default.
- The patch recognizes the v0.5.18/v0.5.19 hook layouts, rejects unknown/partial guards, is idempotent, and regenerates source-checked bytecode. Existing HiSparse, DCP, backend and cache-builder restrictions are not removed.
- Custom compatible images can disable the build patch with `APPLY_SGLANG_DECODE_RADIX_SPEC_PATCH=0`. Existing images and `Dockerfile.sglang.gfx942` do not acquire this engine change automatically. Rebuilding the mi35x image is required; upgrading only the Infera Python package is insufficient.

This does not enable Decode HiCache or session affinity. It does not backport [SGLang #40857](https://github.com/sgl-project/sglang/pull/40857), whose ownership fix addresses hybrid-SWA multi-turn corruption. Hybrid SWA/SSM, EAGLE3 and other speculative algorithms are outside this feature's supported scope. Historical runtime evidence covers GLM-5.2 on the previously patched v0.5.19 build, not a fresh GPU validation of the default v0.5.18 image.

Validation:
- 45 CPU tests pass: 14 Infera argv-forwarding tests plus 31 checks using the unmodified upstream v0.5.18/v0.5.19 admission-hook fixtures and the actual patcher. They reproduce the stock rejection even with opt-in, verify gated radix enablement, preserve unsupported/default cases, exercise DCP/HiSparse/fake-backend rejection, check source drift and idempotence, and inspect regenerated bytecode and Docker wiring.
- The hook tests execute the real release admission branches with a stand-in argument-resolution container; they do not instantiate a GPU KV cache or prove inference correctness.
- The real-SGLang engine test module is skipped locally because SGLang is not installed. No full image rebuild, GPU prefix-reuse run, or real-acceptance accuracy run has been performed for this revision.
- Ruff format/check, fixture Git-blob provenance and `git diff --check` pass.
