===================== HONEST READING OF THE NUMBERS =====================

1. kvd is now PROVEN to serve, not merely connect. gets 0 -> 170 with
   hits=170 / misses=0, 573 MB resident. Step 1's open question is closed.

2. The 2.7x latency drop (0.71s -> 0.26s) is NOT attributable to kvd. kvd's
   counters did not move at all during run 2 — the GPU-side radix cache was
   already warm from run 1, so requests never sank to L2/L3. The speedup is
   GPU prefix-cache reuse. Claiming it for kvd would be wrong.

3. The role weights (20.0/2.0) were verified ACTIVE but their routing effect
   was NOT isolated. With a single prefill worker and a single decode worker
   there is no alternative to route to — the scorer runs but cannot express a
   preference. Measuring the weights needs >=2 workers per role.

4. hits=170 / misses=0 is suspiciously clean. It is consistent with every
   lookup being a repeat of something this same process just stored. It does
   not demonstrate cross-restart or cross-engine reuse, which is kvd's actual
   selling point. That needs a restart-and-reload test.

5. L3 was still backed by the container overlay (/tmp/kvd-long), which kvd
   itself flags: "ssd region long on overlay". long_bytes did grow to 573 MB,
   so the write path works, but this is not a real NVMe measurement.

===================== WORKLOAD DESIGN BUG (worth recording) =====================

The first attempt scored 1/32. Cause was the prompt, not the engine: the system
prefix said "Answer strictly from the reference material below", and GLM-5.2
obeyed it exactly — refusing every question because the reference block (padding
text about "system components") did not mention Paris. Output was fully coherent
throughout; the test was measuring my instructions.

Two fixes: reword the prefix to "background context only -- ignore it unless the
question is about it", and raise max_tokens 32 -> 128 (GLM-5.2 emits a short
reasoning preamble, and 32 truncated before the answer appeared).

Lesson: when a correctness harness reports near-zero on a model that is visibly
producing sane text, suspect the harness first.
