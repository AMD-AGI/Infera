point at the cluster workspace `PD=/shared_nfs/yihou_glm52/dcp_pd_20261021/pd` (and `.../mixrun`, `.../bench`);

## harness/ — PD (Infera same-node 1P1D P4D4) harness

Config chain (each later file sources the earlier one; all knobs are `:=`, so env / `YIHOU_OVERRIDES` win):

| File | Role |
|---|---|
| `bench-harness/config.sh` | Upstream Infera bench-harness defaults (bottom of the chain) |
| `config.yihou.v0521-base.sh` | Node-agnostic GLM-5.2-MXFP4 1P1D P4D4 base (the 22k e2g recipe: TP4 DPA prefill, HiCache, EAGLE 5/1/6). Note: `JSON_MODEL_OVERRIDE_ARGS` is hard-set from `INDEX_SHARE_FOR_MTP` here (ledger.mixrun E2 r4) |
| `config.yihou.E2-target.sh` | 22k "fixed target" deltas on top of the base |
| `config.yihou.dcp.sh` | This task's overlay: image `infera-sglang:v0522-1020-yihou-dcp-mc4340`, optional sglang overlay mount (`SGLANG_OVERLAY`), `DCP_DECODE=N` -> decode TP4 EP4 DP1 no-DPA + `--dcp-size N`, router DP-rank affinity off, `PREFILL_ARM=dpa|tp`, `BOTH/DECODE/PREFILL_ENV_LIST`, `DECODE_CUSTOM_AR` |
| `config.yihou.dcp-e2.mixrun.sh` | E2 variant: decode TP4 EP4 DP2 DPA + `--dcp-size 2`, custom AR on, `HSA_ENABLE_SDMA=0` both legs, knobs `E2_KVB`, `E2_SPLIT` |
