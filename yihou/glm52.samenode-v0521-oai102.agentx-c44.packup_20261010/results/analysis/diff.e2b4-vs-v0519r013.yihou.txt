## 0. Headline finding about r013 itself (affects what "proven" means)
- r013's driver passed EXTRA_ENV=SGLANG_HICACHE_HOST_REGISTER_CHUNK_GB=512 (run.cmd.yihou.sh COMMON[]), but the
  v0519 engine.sh reads only PREFILL_EXTRA_ENV / DECODE_EXTRA_ENV (kvcap scripts/bench-harness/engine.sh:51,64).
  => r013's actual prefill docker env has NO SGLANG_HICACHE_HOST_REGISTER_CHUNK_GB (0 matches in engine-prefill.log).
  r013 ran --hicache-size 450 (server_args hicache_size 450, ratio 1.5) with the DEFAULT 256 GiB chunk, and the v0519
  image chunks the same way (pool_host/common.py:128-136 in the v0519 image). So H1 was LATENT in r013 too; its short
  validation never addressed slots past the first chunk. (config.yihou.274-1p1d-hc450.sh:66 shows the correct form:
  PREFILL_EXTRA_ENV="... SGLANG_HICACHE_HOST_REGISTER_CHUNK_GB=512".)
- e2b4 prefill HAS SGLANG_HICACHE_HOST_REGISTER_CHUNK_GB=512 in the docker env -> (a) intentional H1 fix, and better than r013.
